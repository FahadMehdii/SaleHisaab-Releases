# SaleHisaab — Download

This is where you download the SaleHisaab app for your shop computer.

## Download the App

1. Go to [**Releases**](../../releases) at the top of this page
2. Click the newest version
3. Download the file that ends with `-setup.exe`

## Install the App

1. Double-click the downloaded file
2. If Windows says "Unknown publisher" — click **More info**, then **Run anyway** (this is normal, the app is safe)
3. Click **Next** a few times, then **Install**
4. Open SaleHisaab from your desktop

## First Time Setup

When you open the app, it will ask for your **license key**.
Enter the key we gave you when you bought SaleHisaab.
You need internet one time for this. After that, the app works without internet.

## One Computer or Many?

**Just one computer in your shop?**
You're done. The app saves everything on that computer automatically.

**More than one computer (billing counters)?**
1. On your main computer, install the app as above
2. The app will show an address like `132.178.1.10` at the top — write this down
3. On the other computers, install the app
4. When asked, choose "Connect to another computer" and type that address
5. Now all computers share the same sales and stock data

All computers must be connected to the same WiFi.

## Updating to a New Version

When a new version comes out, the app will show a message at the top:
**"New version available"** with a **Download** button.

1. Click **Download** — it brings you back to this page
2. Download the newest `-setup.exe` file
3. Run it — your sales, products, and settings are kept safe
